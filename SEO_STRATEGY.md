# SEO Strategy for TorqKing Torque Tool Selector

## Overview
This document outlines the comprehensive SEO strategy implemented for the Torque Tool Selector application. The strategy focuses on industrial B2B search optimization, targeting engineers, maintenance professionals, and project managers searching for torque tool solutions.

## 1. Technical SEO Foundation

### Metadata & Tags
- **Title Tags**: Dynamic, descriptive titles with brand name
  - Homepage: "Torque Tool Selector | Industrial Bolting Tool Selection | TorqKing"
  - Results pages: Dynamic titles based on industry and torque requirement
  - Template: "%s | TorqKing" for consistent branding

- **Meta Descriptions**: Compelling, keyword-rich descriptions (150-160 characters)
  - Includes primary keywords: torque tool selector, industrial bolting, tool selection
  - Mentions target industries and applications
  - Clear value proposition

- **Keywords**: Comprehensive keyword list targeting:
  - Primary: torque tool selector, industrial bolting tools
  - Product-specific: B-RAD, DB-RAD, E-RAD, hydraulic torque wrench, bolt tensioner
  - Industry-specific: aerospace bolting, oil and gas bolting, mining bolting
  - Intent-based: torque tool rental, industrial bolting solutions

### Open Graph & Social Media
- **Open Graph Tags**: Optimized for LinkedIn, Facebook sharing
  - Type: website
  - Title, description, image
  - Site name: TorqKing
  - URL: Canonical URLs

- **Twitter Cards**: Summary large image format
  - Optimized for professional sharing
  - Includes logo and key messaging

### Structured Data (Schema.org)
- **WebApplication Schema**: Main selector tool
  - Application category: IndustrialTool
  - Feature list
  - Target audience

- **FAQPage Schema**: Common questions
  - How to select tools
  - Supported industries
  - Available tool types

- **ItemList Schema**: Results page
  - Product recommendations
  - Tool details and categories
  - Brand information (RAD, TorsionX)

- **Product Schema**: Individual tool recommendations
  - Tool names and descriptions
  - Categories and brands
  - Application context

## 3. Technical Implementation

### Robots.txt
- Allows indexing of main selector page
- Disallows dynamic results pages (prevents duplicate content)
- Disallows API routes
- Includes sitemap reference
- Crawl-delay for respectful crawling

### Sitemap.xml
- Generated dynamically via Next.js `sitemap.ts`
- Includes main pages with priorities
- Regular updates for change frequency
- Proper lastModified dates

### Canonical URLs
- Homepage canonical: `https://torqking.com/`
- Prevents duplicate content issues
- Ensures proper indexing

### URL Structure
- Clean, descriptive URLs
- `/results` for results pages (not indexed)
- Query parameters for tool selection (not indexed)
